CANAVAR

A free, lightweight desktop companion for League of Legends (Windows). Built for a small group of Turkish players who wanted something faster and simpler than the big overlay apps.

What it does

  • Champion select: reads the current champion select from the League Client and suggests picks and bans for your role, based on aggregated high-elo match statistics (win rate by matchup, team composition, current patch), plus your own match history.
  • Runes, item sets, summoner spells: when you lock in, the recommended rune page and item set are written to the client through the League Client API. This can be turned off.
  • In-game overlay (informational): small always-on-top boxes showing objective respawn timers based on public game events, your lane statistics compared to average values, an estimate of 1v1 / team-fight strength from levels and items shown on the scoreboard, and the next suggested item. It only displays information; it never controls the game.
  • Personal insights: simple habits from your own recent games (deaths, CS, gold difference at 15 minutes).
  • Friends can share data: a user can export collected match statistics as a file and send it to a friend.

Riot APIs and data used

  • Riot Games API (each user enters their own key): LEAGUE-V4 (Challenger / Grandmaster / Master ladders), MATCH-V5 (match details and timelines), ACCOUNT-V1. Matches are aggregated locally into anonymous statistics (per champion, role, item, rune).
  • League Client API (LCU), locally: champion select session, rune pages, item sets, the user's own match history.
  • Live Client Data API (127.0.0.1:2999), locally: the same public scoreboard and event information the player sees in game.
  • Data Dragon / Community Dragon: champion, item, rune and augment data and icons.
  • Rate limits are read from Riot's response headers and respected; requests stop immediately when the user stops collection.

Fair play

  • No memory reading, no injection, no modification of game files. Compatible with Vanguard by design: only Riot's official local APIs are used.
  • No information hidden from the player is used: no enemy positions, no hidden cooldowns.
  • Suggestions are informational ("you are stronger", "team fight is even"), not automated actions.
  • Optional, off-by-default experimental features read the player's own screen (selected target health bar; ARAM: Mayhem augment card titles). They are clearly labelled and can be removed if required by Riot policy.

Privacy

Canavar has no accounts and no server. All data stays on the user's computer. Nothing is sent anywhere except requests to Riot's APIs and Data Dragon (and, if the user enables it, a version check against the project's GitHub releases). API keys are stored locally and are never included in shared files.

Türkçe

Oyunun belleğine dokunmaz; sadece Riot'un resmi yerel API'lerini kullanır. Hesap ya da sunucu yoktur, tüm veriler bilgisayarında kalır.
